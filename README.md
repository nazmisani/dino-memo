# dino-memo 🦖💜

**Siap, Senior!**: arsip chat pertama Nouval & Dilaa (7–8 Mei 2026), hadiah mensiversary sejak 31 Mei 2026.

Isinya: layar kunci, ucapan Happy Mensiversary, Wrapped, episode lucu, papan quote, surat, dan kupon.

Semua ada di satu file `index.html`. Buka langsung di browser, atau aktifkan GitHub Pages dari branch `main`.

Animasi pakai library open-source: [anime.js](https://animejs.com) (MIT), [canvas-confetti](https://github.com/catdad/canvas-confetti) (ISC), dan [Typed.js](https://github.com/mattboldt/typed.js) (MIT).
